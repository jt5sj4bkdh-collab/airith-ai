# AIRITH AI

AI-powered Telegram crypto research bot.

## MVP

- Telegram bot
- OpenAI Responses API
- Bybit public market data
- BTC/ETH price, 24h change, volume, open interest and funding
- AI-generated research draft
- Manual publication to the Telegram channel

## Commands

- `/start`
- `/status`
- `/market`
- `/draft`
- `/publish`

## Environment variables

- `TELEGRAM_BOT_TOKEN`
- `OPENAI_API_KEY`
- `CHANNEL_ID`
- `OWNER_ID`
- `AUTO_POST_ENABLED`

Never commit real API keys to GitHub.
